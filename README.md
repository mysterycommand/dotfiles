# Dotfiles

Setup:

1. [Install `oh my zsh`](https://ohmyz.sh/#install)
2. [Install `brew`](https://brew.sh/#install)
3. Install stuff with `brew`:
   - `brew install fnm rust deno go coreutils git thefuck`
4. Install stuff with `fnm`:
   - `fnm install --lts`
   - `fnm default lts-latest`
   - `src` (re-source the `.zshrc`)
   - `npm -g i npm` (get latest `npm`)
